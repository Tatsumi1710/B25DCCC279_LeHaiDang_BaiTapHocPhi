# Bài tập Quản lý học phí

## Thông tin sinh viên
- **Họ Tên:** Lê Hải Đăng
- **Mã sinh viên:** B25DCCC279
- **Lớp:** INT1332-20261-18

## Hướng dẫn chạy chương trình
Mở Terminal tại thư mục gốc và chạy lệnh (thay `Cau1` bằng `Cau2`, `Cau3`, `Cau4` tương ứng):
```bash
javac Cau1/Main.java
java -cp Cau1 Main
```
```bash
javac Cau2/Main.java
java -cp Cau2 Main
```
